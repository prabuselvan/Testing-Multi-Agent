# Testing Multi-Agent

## Overview

Testing Multi-Agent is a sample project that demonstrates how to build and coordinate multiple autonomous agents to solve complex tasks. It showcases the use of a central orchestration system, inter‑agent communication, and shared state management.

## Getting Started

### Prerequisites

- Python 3.9 or newer
- `pip` package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/Testing-Multi-Agent.git
cd Testing-Multi-Agent

# (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`

# Install dependencies
pip install -r requirements.txt
```

### Running the Project

```bash
python main.py
```
